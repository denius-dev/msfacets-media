Привет! Я выпускаю PostCraft, компонент для email-рассылок из админки MODX. Вы пишете письмо в чанке, выбираете получателей и окно отправки, а PostCraft рассылает письма по cron и собирает статистику. Один пакет ставится на MODX 2.8 и MODX 3.

Я сделал PostCraft для рассылок на своём рабочем проекте. Теперь выкладываю его отдельным пакетом.

Что внутри

  • Шаблоны писем в чанках с превью для телефона и компьютера — на вкладках «Шаблоны», «Рассылка» и «Страница отписки».
  • Получатели из списка адресов, сохранённых списков и заявок FormIt.
  • Отправка в заданное окно часов: без статистики по адресу — равномерно по окну, со открытиями — в его обычный час.
  • «Не отправлять повторно» с окном в днях и «Фиксированная рассылка» с временным blacklist.
  • Открытия, клики, отписки, возвраты, статистика по адресу и выгрузка в Excel.
  • Страницы отписки для каждого сайта и языка.

Письмо

Шаблон хранится в чанке PostCraft.Имя. PostCraft отправляет его HTML без шапки и подвала сайта, вёрстку письма вы держите под контролем. Редактор берётся из настройки which_editor: CKEditor, TinyMCE или поле HTML. Превью показывает письмо в ширину телефона и компьютера.

В тексте работают два плейсхолдера. {{ mirror }} ведёт на веб-версию письма, {{ unsubscribe }} на страницу отписки. С включённым отслеживанием кликов PostCraft пропускает ссылки письма через свой редирект и считает переходы.

Рассылка

  • Тема, превью-текст рядом с темой во входящих, адрес для ответов и ящик отправителя. Справа — шаблон и его превью на телефоне или десктопе.
  • Адреса вставляются списком, из сохранённого списка или из заявок FormIt. Выбор сохранённого списка сразу подставляет адреса в поле. Дубли PostCraft убирает, адреса из чёрного списка пропускает.
  • Галочка «Не отправлять повторно» смотрит тот же шаблон за указанное число дней (по умолчанию 30). Пропущенные адреса перечисляются в ответе, остальные встают в очередь. Ошибка только если шаблон уже получали все.
  • Галочка «Фиксированная рассылка» после успешной отправки кладёт адреса во временный blacklist на указанное число дней (по умолчанию 7). В этот срок им не уйдёт ни одна рассылка, с любым шаблоном. Срок истекает сам.
  • Тест себе отправляет одно письмо на email вашего профиля и не попадает в статистику.

Вы задаёте день и часы, например с 10:00 до 18:00. Адрес без своей статистики открытий получает время равномерно по окну. Адрес с открытиями за последние 90 дней получает свой обычный час внутри интервала. Рассылку можно поставить на паузу, продолжить, отменить или поправить тему и список адресов до отправки.

Отправка без риска для IP

  • Ящиков отправителя может быть несколько: PHP mail() или SMTP с SSL и TLS.
  • Для хостингов, где сертификат почтового сервера выписан на другое имя, проверку SSL можно выключить у отдельного ящика.
  • У каждого ящика — лимиты в час / в день / за запуск крона и прогрев. 0 берёт системные значения (по умолчанию 60 / 400 / 20).

  • Длинный список раскладывается на несколько дней; на вкладке «Рассылка» видна оценка плана.
  • Автопауза при SMTP-лимите, серии ошибок и высоком % bounce. Cron раз в минуту забирает очередь с учётом лимитов.
  • Каждое письмо несёт заголовки List-Unsubscribe и List-Unsubscribe-Post. Gmail показывает по ним свою кнопку отписки.

Статистика без накруток

Почтовые сервисы и антивирусы загружают картинки из письма в момент доставки. Обычный счётчик записывает это в открытия. PostCraft отсекает запросы ботов, прокси почтовых сервисов и открытия в первые секунды после отправки, поэтому в статистике остаются люди.

По каждой рассылке видно, кто открыл письмо, по каким ссылкам кликали и кто на что нажал. Ещё там причины отписки и адреса, ушедшие в чёрный список. Excel-файл PostCraft собирает сам, ему нужен только модуль zip в PHP.

На вкладке «Статистика» есть поиск по email. Клик по адресу в таблице тоже открывает окно: сводка, какие письма уходили и события по этому адресу.

Отписка и возвраты

Страницу отписки вы пишете целиком своим HTML для каждого сайта и языка, поля открываются в CKEditor или TinyMCE, справа — превью выбранного экрана (телефон или десктоп). Список языков PostCraft берёт из Localizator, а без него из контекстов MODX, как в Babel. Тексты есть на русском и английском. Остальные языки получают английский черновик с плашкой, вы переводите его и сохраняете. Чтобы узнать причину отписки, вставьте в страницу свою форму с полем reason, ответы появятся в статистике.

Если подключить ящик для возвратов по IMAP, PostCraft разберёт недоставленные письма. Несуществующие адреса он внесёт в чёрный список, временные ошибки запишет в статистику. На вкладке Blacklist у постоянных записей в колонке «До» стоит «постоянно», у временных после фиксированной рассылки — дата снятия.

Несколько доменов

Одна установка шлёт письма от имени нескольких сайтов. Ссылки в письме ведут на домен из адреса отправителя: письмо от news@shop.example.org откроется на shop.example.org. Второй домен принимает переходы и отписки и пересылает их на основной сайт с подписью HMAC. Для домена без MODX в пакете лежит отдельный PHP-клиент.

Как подключить

Установите пакет и добавьте задачу в cron:

* * * * * php /path/to/site/core/components/postcraft/cron.php

Потом откройте «Приложения → PostCraft» (в MODX 3 «Пакеты → PostCraft»), проверьте ящик отправителя по шестерёнке и отправьте тест себе.

Требования и цена

  • MODX 2.8 или MODX 3.
  • PHP 7.2 и новее. Для выгрузки в Excel нужен модуль zip, для возвратов модуль imap.
  • Задача cron раз в минуту.
  • Цена 2490 руб., лицензия на один сайт.

PostCraft появится на modstore.pro, как только магазин заработает. Документация будет на docs.modx.pro. Ссылки я добавлю в эту заметку.
